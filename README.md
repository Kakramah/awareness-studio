# استوديو التوعية

أداة عربية تعمل في المتصفح لصناعة منشورات وبوسترات التواصل الاجتماعي. تضم محرر طبقات، قص الصور وضبطها، مقاسات متعددة، وقوالب وتصديراً للتصاميم.

**الأداة المنشورة:** https://kakramah.github.io/awareness-studio/

## قبل التعديل

- اقرأ [BRIEF.md](BRIEF.md) لفهم نموذج المستند ومسار الرسم والتصدير وقواعد الهوية.
- اقرأ [DESIGN.md](DESIGN.md) لقرارات التصميم.
- راجع تأثير التغيير في المعاينة **والتصدير**؛ كلاهما يعتمد مسار الرسم نفسه بحسب بريف المشروع.

## البنية

- `index.html` و`style.css`: الواجهة.
- `js/`: منطق المستند، الرسم، التحرير، اللوحات والتصدير.
- `data.js` و`topic-packs.js`: بيانات الأداة.
- `assets/` و`images/` و`fonts/`: الأصول البصرية والخطوط.

## المعاينة

من جذر المستودع شغّل:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/`. اختبر إنشاء تصميم، تعديل طبقة، تبديل المقاس، الحفظ والتصدير بعد أي تغيير مؤثر. التطبيق بلا خادم ولا خطوة بناء في جذر المستودع؛ بعض الأيقونات تُحمّل من CDN وتتطلب اتصالاً بالشبكة.
